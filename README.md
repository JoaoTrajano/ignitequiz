# IgniteQuiz

**IgniteQuiz** é uma aplicação de quiz interativa onde os usuários podem testar seus conhecimentos de forma dinâmica. A aplicação exibe questões com múltiplas alternativas e calcula o desempenho dos participantes com base nas respostas corretas.

---

## **Tecnologias Utilizadas**

- **React**: Biblioteca JavaScript para a criação de interfaces de usuário dinâmicas e reativas. O React permite atualizar a UI de forma eficiente, com base no estado da aplicação.
  
- **TypeScript**: Superset do JavaScript, que adiciona tipagem estática à linguagem, ajudando a evitar erros e melhorando a manutenção do código.

- **Styled-components**: Biblioteca para estilização de componentes no React, permitindo criar estilos em JavaScript de forma modular e reutilizável.

- **React Router**: Usado para navegação entre diferentes telas e componentes, permitindo que a aplicação tenha múltiplas páginas sem recarregar o navegador.

- **Context API**: Utilizada para o gerenciamento de estado da aplicação, permitindo o compartilhamento de dados entre componentes sem a necessidade de passar props manualmente.

---

## **Funcionalidades**

- ✅ Exibição de perguntas com alternativas.
- ✅ Marcação e validação de respostas.
- ✅ Sistema de pontuação para respostas corretas.
- ✅ Tela de resultados com o desempenho do usuário.
- ✅ Contagem regressiva para o tempo de resposta.
